The literature behind monoprop's methods and the problems it targets. The
Majorana-propagation method itself is introduced in [@Miller2025-aj], with its
scalable circuit-generation extension in
[@chakraborty2026scalablequantumcircuitgeneration]. We recommend an intuitive description
of Majorana operators and their connection to qubits space via Fermion-to-qubit mapping
described in [@Miller2023-bonsai]. Other representative large-scale applications appear in
[@Kim2023-bj] and [@Hartnett2026-ou].
