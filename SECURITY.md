# Security Policy

## Reporting a Vulnerability

To report vulnerabilities, you can privately report a potential security issue via the Github security vulnerabilities feature. This can be done here:

https://github.com/Algorithmiq/monoprop/security/advisories/new

Please do not open a public issue about a potential security vulnerability.

You can find more details on the security vulnerability feature in [this Github guide](https://docs.github.com/en/enterprise-cloud@latest/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
