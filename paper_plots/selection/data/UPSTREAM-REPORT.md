# Gate-selection scaling

Selection time is the three phases measured inside the engine (pool and gradients, the
occupation-flip table, scoring); building and evolving the observable happen before the
clock starts. Single partition, single thread. `pairs` is the enumerated
(state support, candidate) count, `K` the tracked monomials, `diag` the tracked diagonal
monomials the flip table is built from.
